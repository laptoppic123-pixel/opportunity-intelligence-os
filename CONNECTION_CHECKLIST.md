# Connect once after BUILD — READY_FOR_CREDENTIALS

Never paste secrets in chat. Keep the live/paid/scheduler flags OFF while adding credentials. No paid account, auto top-up, plan upgrade or recurring service is required by BUILD.

1. **Required: dedicated Supabase project and server key.** Use the existing [Opportunity Intelligence OS project](https://supabase.com/dashboard/project/vaxesikpcgrdxzqikyur), not a DMS/n8n project. Get the project URL and an enabled modern **secret** API key from [API Keys](https://supabase.com/dashboard/project/vaxesikpcgrdxzqikyur/settings/api-keys). Enter `SUPABASE_URL=https://vaxesikpcgrdxzqikyur.supabase.co` and `SUPABASE_SECRET_KEY` in local `.env` and repository Actions **Secrets**. Legacy `SUPABASE_SERVICE_ROLE_KEY` is supported locally for compatibility; the supplied Actions use the modern variable. Publishable/anon keys are insufficient for this private backend. Generate one stable UUID using `uv run python -c "import uuid; print(uuid.uuid4())"`; save it as `OI_OWNER_ID` in local `.env` and repository Actions **Variables**. Keep `OI_EXPECTED_PROJECT_REF=vaxesikpcgrdxzqikyur` locally. The service key is privileged and stays on trusted Python servers; there is no browser key field.

2. **Required for cloud runs: private GitHub repository settings.** Use [Actions Secrets](https://github.com/laptoppic123-pixel/opportunity-intelligence-os/settings/secrets/actions) for secret values and [Actions Variables](https://github.com/laptoppic123-pixel/opportunity-intelligence-os/settings/variables/actions) for non-secret controls. Set `OI_ACTIVATED=false`, `OI_LIVE_ENABLED=false`, `OI_PAID_ENABLED=false`, `OI_SCHEDULES_ENABLED=false`, `OI_MONTHLY_LIMIT_USD=20`, `OI_INTERNAL_PAID_STOP_USD=19`, and the stable `OI_OWNER_ID`. Check [Billing usage](https://github.com/settings/billing/usage) and [budgets/spending controls](https://github.com/settings/billing/budgets); set an Actions budget that stops usage beyond your included allowance. Do not assume free trial credits renew. Local `.env` is copied from `.env.example` and ignored by Git.

3. **Optional AI: OpenRouter.** Create a legitimately owned key at [OpenRouter Keys](https://openrouter.ai/keys). Set `OPENROUTER_API_KEY` in GitHub Secrets and local `.env`; use the provider's own key limit. After activation authorization, enable `openrouter` and verify `current_terms_checked` in `configs/sources.yaml`, then run `oi --live models --refresh`. Only then choose exact IDs/prices from the live [model catalog](https://openrouter.ai/docs/api/api-reference/models/get-models). Enter `FAST_MODEL`, `DEEP_MODEL`, `CRITIC_MODEL` in local `.env` and GitHub Variables. Use zero-priced models first; leave any unused role blank. A critic must differ from the generating model to be independent. Without a key or role selection, the pipeline remains explicitly rules-only.

4. **Optional quality upgrade: Exa and Tavily.** Obtain keys through [Exa](https://exa.ai/) and [Tavily](https://www.tavily.com/). Set `EXA_API_KEY` and `TAVILY_API_KEY` in GitHub Secrets and local `.env`. Leave both providers disabled until their terms, documented per-request worst-case cost, credit type, `credit_headroom`, `credit_checked_at` (UTC ISO timestamp), quotas and actual added information value are reviewed. No trial balance, request price or renewal is assumed. Paid-priced requests still need explicit paid authorization; simply entering a key never enables them.

No Haimaker endpoint/model/price is preset. Other supported keys: `SERPER_API_KEY` ([Serper](https://serper.dev/)), `YOUTUBE_API_KEY` ([Google Cloud credentials](https://console.cloud.google.com/apis/credentials), enable [YouTube Data API](https://developers.google.com/youtube/v3)), `OPENALEX_API_KEY` ([OpenAlex](https://openalex.org/)), and a source-specific `PROCUREMENT_API_KEY` with reviewed endpoint/field mapping. Optional higher public GitHub allowance: `SOURCE_GITHUB_TOKEN` ([GitHub token settings](https://github.com/settings/personal-access-tokens)), minimal public-read access only. Optional `STACKEXCHANGE_KEY` via [Stack Apps registration](https://stackapps.com/apps/oauth/register). Keys go in both secret locations. Review current access terms; RSS/changelog URLs must be permitted and explicitly listed. Reddit/G2 remain OFF without legitimate access.

The activated backup command creates/verifies the **private** `oi-private-backups` Storage bucket. It never makes it public.
